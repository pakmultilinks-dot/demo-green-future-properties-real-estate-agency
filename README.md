# Green Future Properties - Free Demo Concept Website

This is a **free demo concept website** for **Green Future Properties** (real estate agency), located at 148 B, Commercial Broadway, DHA Phase 8, Lahore. It was created by a Lahore web designer to show what a professional website for the business could look like, before they order one.

**Important:** This is NOT the business's official website. All contact details, services, and timings shown are illustrative demo content, not verified facts about the business. The phone number +92 300 0000000 is a placeholder demo number.

## What's inside

- Hero with floating investment-info cards and WhatsApp CTA
- Services in 3 numbered steps: Residential Sales, Commercial Property, Plots/Files & Investment
- Areas-served cards: DHA Phase 8, DHA Phase 5, DHA Phase 6, Bahria Town, Cantt, Gulberg
- Property enquiry form with intent/type/area fields (demo, no data sent)

## Run

Open `index.html` in any browser. Fully self-contained: no external images, works offline.
